# Map boundary source

`ne_50m_admin_1_us_canada.geojson` contains the 64 USA/CAN features selected
by `properties.adm0_a3` from Natural Earth's 1:50m admin-1 states/provinces GeoJSON.
Coordinates and source properties are retained; the global file is not bundled.

- Source: https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_admin_1_states_provinces.geojson
- Official repository: https://github.com/nvkelso/natural-earth-vector
- Dataset page: https://www.naturalearthdata.com/downloads/50m-cultural-vectors/
- Retrieved: 2026-10-10
- License: public domain; https://www.naturalearthdata.com/about/terms-of-use/

Made with Natural Earth. Region representative points used for
pairwise geographical distances come from `plantmine/data.py`, rather than
these polygons; they are approximate administrative locations.
